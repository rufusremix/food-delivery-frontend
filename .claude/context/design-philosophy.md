# Design Philosophy

FoodFlow prioritizes:

- Consistency over creativity
- Clarity over decoration
- Reuse over duplication
- Simplicity over complexity

The application should feel:

- Professional
- Structured
- Predictable
- Trustworthy

Before creating a new component, variant, or pattern:

1. Can an existing component be reused?
2. Is this a new semantic concept or only a visual difference?
3. Will this make the design system more consistent?

Prefer reusable primitives over page-specific solutions.
