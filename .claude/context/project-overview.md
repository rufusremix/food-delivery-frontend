# Project Overview

FoodFlow is a frontend-focused food delivery application built to demonstrate production-grade frontend architecture, UI engineering, design system thinking, and React development practices.

The goal is not to replicate Swiggy or Zomato feature-for-feature. Instead, the goal is to showcase how a modern React application can be designed and structured using scalable frontend patterns.

The application focuses on:

- Feature-based architecture
- Reusable UI primitives
- Design systems and design tokens
- Light and dark mode support
- Accessibility
- Component composition
- Responsive layouts
- Maintainable code organization
- Type safety

This project should feel like a real product rather than a tutorial application.

When suggesting implementations, prioritize maintainability, readability, and reuse over shortcuts.

Avoid creating unnecessary complexity. The project should demonstrate strong engineering judgement and simplicity rather than enterprise-scale abstractions.
